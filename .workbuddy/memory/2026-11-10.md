## 局域网/手机访问（用户要求「按 A」）
- 起因：手机同 WiFi 打不开本地 8000。根因 `server.sh` 把 uvicorn 写死 `--host 127.0.0.1`，
  实测 `lsof` 只有 `127.0.0.1:8000`，`curl http://192.168.128.77:8000/` 返回 000。
  前端请求全相对路径、后端无 Host/Origin 校验/CORS、macOS 应用防火墙 disabled，
  无 `navigator.clipboard`/`crypto.subtle` 等 HTTPS-only API → 换 IP 访问无额外障碍。
- 改 `server.sh`：新增 `MC_HOST`（默认 `0.0.0.0`）经 `ENVARGS` 传到 python 引导段，
  `os.execv` 用 `host`；`MC_HOST=127.0.0.1 ./server.sh start` 可回退到只本机。
  start 成功时额外打印局域网地址（取 `ipconfig getifaddr en0`）。
- 验证：`bash -n` PASS；`stop && start` 后 `lsof` = `*:8000 (LISTEN)`；
  从 `192.168.128.77` 访问 `/`、`/app.js`、`/api/me` 全 200，`127.0.0.1` 仍 200；
  两个会话文件都在。⚠️ 重启后自动炼卡/换卡引擎 stopped，需界面重新点开始。
- ★ 手机登录**不用扫码**：登录页 `/api/login/sessions` 从局域网 IP 实测返回 2 个已登录会话
  （0003822843 / 0004821992），点选沿用即可 —— 会话文件在服务端 `/tmp/mc_sessions/`，
  与访问设备无关。上一轮答复里「手机要重新扫码」是错的，已更正。
  「QQ 一键登录」按钮只在 MQQBrowser UA 显示，其回调是 `location.origin + /api/login/mobile_cb`，
  手机上会变成内网 IP、QQ 服务器回不来 → 手机别用这个按钮，走会话沿用或扫码。
- ★ 安全：`/api/login/sessions` 无鉴权直接返回 token（自用部署设计），绑 `0.0.0.0` 后
  同网段任何人都能拿到全部账号登录态。只在可信 WiFi 用，不用时 `MC_HOST=127.0.0.1` 回退。
