## 移动端多栏界面"操作区域重叠"（2026-11-01 修复）
- 现象：tab 能点后，好几个界面（自动炼卡/换卡/灵宠/卡库/比赛等用 grid 多栏的 pane）操作区域互相重叠。
- 根因：移动端 ≤768px 块原用 `grid-template-areas:none !important` + `grid-template-columns:minmax(0,1fr)!important`（`grid-template-rows:auto!important`）把这些容器（.cards-grid/.lib-body/.ex-grid/.sp-grid/.au-grid/.match-pane）强制单列。但这些容器在父链里是 `flex:1;min-height:0`（高度受限），单列 `grid-template-rows:auto` 在内容超高时**溢出容器**（grid 默认 `overflow:visible`），溢出内容盖到下方/底栏 → 视觉重叠。
- 桌面 1080/1240 断点虽也做单栏，但 grid-template-areas 残留 + 受限高度的组合在 iOS 上易触发。jsdom 不计算布局，无法本地复现，只能真机/无头渲染验证。
- 修复：≤768px 块改为把这些容器**强制 `display:flex!important; flex-direction:column!important`** 并 `grid-template-*:none!important; overflow-y:auto; gap:8px`，子项 `flex:0 0 auto; min-height:0` → 纵向堆叠、整页/容器滚动，彻底消除 grid 残留溢出叠加。仅影响 ≤768px，桌面不变。
- 教训：**本地无浏览器（无 chromium/playwright），iOS 布局 bug 无法本地渲染验证**，必须请用户真机截图闭环，不要靠静态 CSS 推理下结论。

## 移动端"每日比赛子tab泄漏到所有界面"（2026-11-01 修复）
- 现象：手机上"每日比赛"页（含子tab栏 猫窝日常/出战/工会/西游记/三国）出现在每个主界面。
- 根因：移动端 ≤768px 块把 `.match-pane` 列进 `.cards-grid,.au-grid,...,.match-pane{display:flex!important}` 强制组。而隐藏用 `.hidden{display:none!important}`（L395）。两者**特异性相同（单 class）**，CSS 后定义者胜 → L869（媒体查询，晚于 L395）的 `display:flex!important` 覆盖了 `.hidden`，导致 `pane-match` 即使带 `hidden` class 也始终 `display:flex`。只有直接等于 pane 的元素（`.match-pane`）会泄漏；其他 pane 被强制的是它们的**子容器**（.au-grid 等），父 hidden 时子不可见，不受影响。
- 修复：`.match-pane` 从 `display:flex!important` 组摘出，单独只设 `flex-direction:column!important` + `grid-template-*:none!important` + `overflow-y:auto`，**不强制 display**；display 仍由 `.pane{display:flex}` 提供，`.hidden` 因此能正常隐藏它。版本 bump 20261101e。
- 铁律：**移动端对任何 `pane` 类元素不要用 `display:flex!important` 之类的强制 display**，否则会盖掉 `.hidden` 造成整页泄漏。只改方向/清理 grid，display 交给 `.pane` 基础规则。
