## 架构定案（用户拍板）
- 用户明确：**要纯 HTML 界面 + 本机薄代理**，不要重后端、不要强制 Chrome/扩展。即方案 A。
- UI 仿 QQ 空间登录风格：二维码（可刷新）+ 本机 QQ 快速登录 两种入口。
- 实测边界：qq.com 接口**无 CORS 头**（curl 确认）→ 纯浏览器 fetch 跨域读不到响应；登录态 cookie 跨源隔离 → 纯 HTML 单文件零后端/零扩展**不可行**，必须有一个同源代理（本机薄代理或扩展）。
- 快速登录：纯 web + 薄代理在 **macOS** 上无法读取本机 QQ 登录令牌（依赖腾讯客户端私有本地协议，主要为 Windows），故 /api/login/quick 诚实返回 available:false，UI 提供「唤起本机 QQ」(tencent://) 降级。扫码登录是 Mac 上稳的路。
- card.show.qq.com **已死**（curl 无响应），真实 2026 域名需登录后现探。
- 当前交付：backend/main.py(薄代理+登录+静态)+ frontend/index.html(QQ风登录)+ app.js；服务经 run_in_background 持久运行于 :8000。用户在自有浏览器开 http://localhost:8000 扫码/刷新；登录态存服务端内存。

## p_skey 根因定位（11:25 后）——推翻"玩吧会话"结论
- **关键纠正**：-1100 的真正原因不是"需要玩吧会话"，而是**缺空间(qzs.qq.com)的 p_skey**。用户提示「金鱼登录时显示 qq农场」→ 农场/卡片/空间同属空间体系，接口要的是 **p_skey（qzs.qq.com 域）**，不是 skey（qq.com 域）。
- 实测证据：session cookie 清单只有 `['qrsig','pt2gguin','ETK','pt_recent_uins','superuin','supertoken','superkey','ptnick_*','uin','skey','RK','ptcz']`——**无 p_skey / p_uin**。用 skey 算 g_tk 调 card_user_random_get 恒 -1100。
- 又实测：带 skey 直接 GET `qzs.qq.com/qzone/`、`loginsucc.html`、`user.qzone.qq.com/<uin>` 均返回 200 但**不签发 p_skey** → 证明 p_skey 只在**登录流程的 check_sig 跳转**时下发。
- **根因**：`auth_qr.py` 的 U1（回跳）设成了 `gamebar/direct.html`（移动端 hybrid 壳，靠原生 JS bridge），check_sig 跳到它**不签发空间 p_skey**。
- 修复：
  1. `auth_qr.py`：U1 改为 `https://qzs.qq.com/qzone/`（空间主页），让 check_sig 签发 p_skey。
  2. `mc_api.py`：新增 `_session_key()`（优先 p_skey 算 g_tk）、`_inject_qq_cookies()`（手动注入 p_skey/skey/uin/p_uin，因为 card.show.qq.com 不会自动带 qzs.qq.com 的 cookie）；`get`/`probe_api`/`enter_game` 统一改用之；`restore()` 恢复 cookie 时统一设 domain=`.qq.com`。
  3. `main.py`：logout 改 `@app.api_route(..., methods=["GET","POST"])`（原先只支持 GET，前端 POST 时 405）。
  4. 新增 `backend/verify_p_skey.py`：轮询 /api/me 等登录 → 检查 session 是否含 p_skey → 分别用 p_skey/skey 算 g_tk 实测接口对比 → 结果写 /tmp/p_skey_verify.json（供用户扫码后自动验证，无需告知）。
- 待验证：用户重扫后看 p_skey 是否出现、card API 是否还 -1100（由 PcRAxR 后台脚本自动跑）。
- 概念澄清（已告知用户）：QQ 互联 open.qq.com 的三方 OAuth 只能拿 openid/access_token，**拿不到也不该拿到 qq.com 内部服务会话**，调不了 card.show.qq.com；助手必须拿到 qq.com/qzs.qq.com 内部登录态，故必须经本机代理/扩展。
